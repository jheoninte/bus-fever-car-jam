# DEV QUICKSTART

## 목표

- 차량 상태, 슬롯 상태, 레벨 시드를 분리해 레벨/솔버/메타 개발을 병렬로 진행할 수 있게 합니다.
- 현재 HTML5 검증본을 기준으로 후속 상용 엔진에서도 같은 JSON 시드를 재사용하도록 유지합니다.

## 실행

```bash
npm install
npm run dev
```

## 추천 첫 작업 순서

1. 차량 상태와 버스 슬롯 상태를 별도 스토어로 분리합니다.
2. `data/levels_seed.json` 기반 레벨 로더를 추가합니다.
3. `normal`, `mystery`, `frozen`, `tunnel` 기믹 처리를 데이터 중심으로 옮깁니다.
4. 색약 모드 심볼 시스템을 UI 렌더러와 분리합니다.

## 첫 스프린트 산출물

- 레벨 파서/검증기
- 상태 전이 함수 정리
- 실패/막힘 판정 로직 분리
- 솔버 실험용 로그 출력 추가
