# Core Mechanics

## 장르와 코어 루프

서버 없는 캐주얼 주차·색상 퍼즐입니다. 차량 방향, 대기열 선두 색상, 정류장 여유를 보고 출차 순서를 결정합니다.

1. 앞길이 트인 차량을 탭하면 표시 방향으로 직선 출차합니다. 주차 차량이 경로를 막으면 이동할 수 없습니다.
2. 출차 즉시 정류장 한 칸을 예약합니다. 정류장은 항상 4칸이며 버스도 한 칸을 사용합니다.
3. 도착한 차량에 대기열 선두의 같은 색 승객이 자동 탑승합니다. 1칸 차량 정원은 4명, 2칸 버스는 6명입니다.
4. 만석 차량이 출발하면 정류장을 비웁니다. 승객 전원 탑승과 모든 차량 출발을 만족하면 클리어합니다.

이동 중 차량과 자동 탑승 가능성이 없고, 정류장이 가득 차거나 합법적인 출차가 없으면 실패합니다. 실패 후 재도전할 수 있습니다. 광고 부활은 차량 한 대가 출발할 수 있게 대기열을 복구하며 이후 모든 선택의 성공을 보장하지 않습니다.

## 기믹과 접근성

- `normal`: 선두 승객과 색상이 맞을 때 탑승합니다.
- `mystery`: 주차 중 색을 숨기고 정류장 도착 시 공개합니다.
- `frozen`: 표시된 열쇠 색 승객이 대기열 선두에 오면 해동합니다. 해동은 유지되며 잠긴 동안 탭 출차할 수 없습니다.
- `tunnel`: 선두 매치를 우선 처리한 뒤 뒤쪽에 있는 차량 자신의 색 승객을 먼저 태울 수 있습니다. 다른 색 승객은 소비하지 않습니다.
- 차량과 승객에 같은 색상 문자(R/B/Y/G/P/C)를 표시합니다. 상점에서 기호 설정을 켜면 ●/▲/◆/■/✦/✚로 함께 바뀌며 저장됩니다. 얼음에는 해제색 기호도 표시합니다.

## 데이터와 검증

게임과 솔버가 `data/levels_seed.json`의 명시적 차량 배치와 승객 순서를 함께 읽습니다. 레벨 데이터 schemaVersion 2는 저장 Schema v3와 별개입니다. 차량·정류장·레벨 데이터는 분리하고 실제 출차·탑승·출발·실패 판정은 `puzzle-engine.js`와 `rules.js`를 공유합니다.

진행 중 각 색의 **대기 승객 수 = 해당 색 차량의 남은 좌석 합계**를 보존합니다. 초기 상태에서는 남은 좌석과 전체 정원이 같습니다. 부스터·광고·구매 없이 최소 한 개의 해답을 검증하며 모든 선택의 성공을 요구하지 않습니다.

1~5 일반, 6~10 물음표, 11~15 얼음, 16~20 터널을 단계적으로 도입하며 한국어 안내를 표시합니다. 20레벨 완료 후 챕터 완료와 마지막 레벨 재도전을 제공합니다. 검증되지 않은 21레벨은 만들지 않습니다.

난이도와 솔버의 범위는 [레벨 표](02_Level_Balance_1_to_20.md), [검증 기록](10_Level_Verification.md)을 참고합니다.
