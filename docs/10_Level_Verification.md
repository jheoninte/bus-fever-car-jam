# 20레벨 규칙·해답 검증

## 적용 범위 (2026-11-17, Windows)

Gemini의 초반 20레벨 설계를 수량·도입 순서·목표 시간·한국어 튜토리얼에 반영했습니다. `data/levels_seed.json`은 레벨 데이터 schemaVersion 2이며 각 레벨에 격자 크기, 정류장 수, 차량 ID·좌표·방향·길이·색·기믹, 승객 배열을 명시합니다. 저장 Schema v3는 별도입니다.

`level-loader.js`는 데이터 검증 후 상태를 만들며 누락 레벨을 무작위 생성하지 않습니다. `level-schema.js`가 겹침·격자 범위·차량 방향/셀 순서·정원·색별 수량·해제색 존재·기믹 도입 시점을 확인합니다. 버스 6명/소형차 4명, 정류장 4칸을 고정합니다.

## 공유 규칙과 원안 보정

- 게임 UI와 솔버가 `puzzle-engine.js`의 출차 예약·도착·탑승·출발·클리어/실패 판정을 공유합니다. 경로·선두 매치·해동·터널 검색은 `rules.js`를 사용합니다.
- 진행 중 보존식은 “색별 대기 승객 = 색별 남은 좌석”입니다. 원안의 “항상 전체 정원과 같다”는 탑승 후 성립하지 않아 보정했습니다.
- 얼음은 해제색 선두 도달 후 해동 상태를 유지하며 잠긴 차량은 출차할 수 없습니다. 터널은 자신의 색만 소비합니다. 기존 다른 색 터널 필드가 런타임 규칙을 바꾸지 못합니다.
- 물음표는 정류장 도착 때 공개합니다. 차량·대기열·해제색에 같은 기호를 사용하고 기호 모드를 저장합니다.

## 해답·실패 재생

`solver.js`는 상태를 복제하고 깊이 우선 탐색과 상태 중복 제거를 사용합니다. 차량 하나를 출차하고 가능한 자동 탑승·해동·출발이 모두 끝난 후 다음 차량을 선택합니다. 부스터·광고·결제는 사용하지 않습니다.

20개 레벨 모두 `solved` 경로를 찾고 초기 상태에서 다시 재생하여 전원 탑승, 빈 대기열, 승객 보존을 확인했습니다. 8레벨은 물음표 버스, 13레벨은 얼음 버스를 포함하며 16~20 해답에는 실제 터널 우회 탑승이 있습니다. 4~20레벨은 무작위 정책에서 발견한 실패 경로도 재생합니다.

`data/level-verification.json`에 해답 차량 ID 순서, 방문 상태 수, 터널 우회 수, 무작위 정책 결과와 첫 실패 경로를 저장합니다. 검증기는 실제 재계산 결과와 기록을 비교합니다. 수량과 지표는 [밸런스 표](02_Level_Balance_1_to_20.md)에 있습니다.

## 재현 명령

```bash
npm run generate:levels
npm run validate:levels
npm run check
npm run validate:bundle
```

`generate:levels`는 결정적 생성 규칙으로 두 데이터 파일을 덮어씁니다. 수작업으로 배치를 바꾼 뒤에는 생성기를 다시 실행하면 해당 편집이 사라지므로 생성 규칙을 수정하거나 별도 팩으로 관리합니다. 빌드는 원본과 dist의 레벨 팩을 모두 검증합니다.

## 남은 검증

- 순차 정책은 실시간 동시 출차의 모든 순서를 탐색하지 않습니다. `no_sequential_solution`은 전체 게임에서 절대 불가능하다는 증명이 아닙니다. 탐색 예산 초과는 `budget_exhausted`로 구별합니다.
- 솔버는 물음표의 내부 색을 압니다. 숨겨진 정보를 모르는 플레이어의 합리적 선택으로도 풀리는지는 증명하지 않았습니다.
- 무작위 100회는 고정 정책의 측정이며 사람의 승률이 아닙니다. 목표 시간·난이도 상승·해동 체인의 교육 효과는 사람의 플레이 테스트가 필요합니다.
- VIP/셔플 후보의 해답 확인과 중간 퍼즐 저장/재개는 이후 구현했습니다. [추가 검증 기록](11_Resume_and_Boosters_QA.md). [무료 힌트](12_Hints_and_Hidden_Colors_QA.md)도 구현했으며 물음표 실제 색 필드를 사용하지 않습니다. 완전한 공개 정보 의사결정 정책은 아직 증명하지 않았습니다.
- 실제 iOS 네이티브 서비스와 WKWebView 실기기 테스트는 이 기록의 범위 밖입니다. [iOS 인계](04_iOS_Release_Handoff.md).
