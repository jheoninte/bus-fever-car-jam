# 버스 정류장 비주얼과 탑승 연출

## 적용 범위

밝은 공원형 정류장, 보도와 지붕, 번호가 있는 승차장, 주차장과 조경을 추가했습니다. 차량은 타이어·유리 반사·측면 창·좌석 표시·방향 화살표가 있는 장난감 버스로 바꿨습니다. 대기 승객은 줄에서 조금씩 움직이고, 탑승할 때 다리를 번갈아 움직이며 버스 문으로 걸어가 사라집니다. 탑승이 끝난 만석 버스는 안내 문구와 작은 배기 효과를 남기며 출발합니다.

차량·슬롯·시드와 기믹 태그, 원본 레벨 JSON, 솔버와 저장 스키마는 유지합니다. 탑승 애니메이션 중 표시 좌석 수만 늦게 갱신하며, 실제 승객 수와 출발 보상·슬롯 해제는 기존 규칙으로 먼저 저장합니다. 재시작 때 이전 연출과 타이머를 취소하고, 화면 크기 변경 때 진행 중 주행을 완료 처리해 새 배치에 정렬합니다. 모션 줄이기 설정은 보행 시간을 줄이고 반복 움직임·배기 효과를 생략합니다.

**아트 출처: code-drawn, no image model.** 로컬 이미지 생성은 시간 초과됐고 복구할 산출물이 없었으며, 이미지 API 경로도 구성되어 있지 않았습니다. Phaser 그래픽으로 만든 독자적인 2D 벡터풍 아트입니다. 참조 이미지의 3D 모델이나 비트맵을 복제하지 않았습니다. [출처 메타데이터](art/codeart-meta.json).

## Windows 검증 결과

- `npm run check` 통과: 기존 레벨·플레이·저장·힌트·플랫폼 검사와 새 프레젠테이션 검사.
- `validate:presentation`: 20개 레벨 × 4개 화면 크기, 대기열/보드 경계, 방향별 출차 경로, 지연 출발 전 저장, 이전 라운드 콜백 무효화, 결과창 대기, 모션 줄이기 검사 통과.
- 브라우저 UI: 스테이지 1의 8/16부터 16/16까지 탑승·출발 후 클리어, 스테이지 2 진입·재시작, 주행 중 화면 크기 변경 후 탑승 지속, 상점 열기·닫기, 색약 모드 문자→도형 확인.
- 실제 브라우저 320×568, 390×667, 390×844 화면 확인. 320px 화면에서는 주차장과 버스가 작아집니다.
- 브라우저 오류·경고 로그 없음.
- `npm run prepare:ios` 통과: CSS MIME 허용과 28개 자산의 현재 소스/해시 일치. 네이티브 호스트 XCTest에 CSS 응답 검사 추가.

브라우저 QA는 별도 포트 4186에서 수행해 사용자 플레이 포트 4185의 진행 데이터를 보존합니다. 스크린샷은 `docs/qa/toy-station-390x844.jpg`, `toy-boarding-390x844.jpg`, `toy-station-320x568.jpg`입니다.

## Mac에서 남은 확인

Swift 컴파일·XCTest는 Windows에서 실행하지 않았습니다. iPhone 안전 영역, WKWebView 렌더링, 고해상도 기기의 메모리·프레임 속도, 모션 줄이기, 중단·복귀와 네이티브 광고/결제 창을 실제 기기에서 확인해야 합니다. 이번 비주얼 변경만으로 출시 준비 완료를 의미하지 않습니다.
