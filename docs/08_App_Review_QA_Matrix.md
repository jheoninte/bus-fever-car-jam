# App Review QA Matrix

아래는 실행할 시나리오입니다. Windows의 JS 검증 통과를 실기기/Sandbox 통과로 기록하지 않습니다. Mac에서 결과·OS·기기·SDK 버전과 증거를 남깁니다.

## StoreKit Testing / Sandbox / TestFlight

Xcode에서 상품 4개를 매핑 문서와 동일한 ID/타입으로 생성하고 Scheme의 StoreKit Configuration에 연결합니다. 로컬 설정은 서명 검증 실패 같은 StoreKit Testing 시나리오용이며 실제 App Store 네트워크/계정은 Sandbox와 TestFlight에서 따로 검사합니다.

| 상황 | 기대 결과 |
|---|---|
| 비소모성·소모성 정상 결제 | 정확한 상품과 거래 ID 확인, 1회 지급, 영구 저장 후 finish |
| 사용자 취소 | 재화·권한 변경 없음, 재시도 가능 |
| Ask to Buy / pending | 승인 전 무지급, 승인 업데이트를 큐에 보존해 재개/실행 시 1회 지급 |
| unverified, 상품/거래 ID 불일치, 미등록 상품 | 무지급·미finish |
| 구매 버튼 연타 / 같은 거래 재전달 | 결제 UI 중복 요청 차단, 동일 ID 1회 지급 |
| 지급 전 강제 종료 | unfinished 재조회로 복구 |
| 지급·원장 저장 직후 finish 전 강제 종료 | 재실행 후 추가 지급 없이 finish 재시도 |
| 저장 실패 / 용량 부족 | finish 금지, 미완료 거래 보존, 정상화 후 복구 |
| finish 실패 | 지급 유지, 같은 거래 재처리 시 중복 지급 없음 |
| 구매 복원 연속 실행 | 비소모성 권한만 복원, 소모성 재지급 없음 |
| 스타터 번들 기기 변경·재설치 | 원장 복구, 영구 권한 반영, 일회성 재화 중복 지급 없음 |
| 환불/권한 철회 | 광고 제거/배율 해제, 일회성 지급 원장 유지 |
| 네이티브 브리지 일부/전체 누락 | 구매·광고 보상·ATT 승인 성공 처리 없음 |

## ATT / 광고

- 새 설치에서 notDetermined일 때만 OS 요청. 거부·restricted·설정 변경·background→active를 확인합니다.
- ATT 허용/거부에 게임 기능·재화 차이가 없어야 합니다. 허용을 유도하는 보상 문구를 쓰지 않습니다.
- UMP 동의 필요/불필요/거절/오프라인/설정 재열기 경로를 검증합니다. 광고 요청은 canRequestAds 및 개인정보 설정을 따릅니다.
- Debug는 테스트 광고, Release는 실제 광고 단위. 스토어 상품 ID는 환경이 바뀌어도 같습니다.
- reward callback에만 1회 지급. 중도 종료/no-fill/표시 실패/중복 callback/연타는 추가 지급 없음.
- 부활은 현재 실패 스테이지에만 적용. 광고 도중 재시작·앱 재개에도 다른 스테이지에 보상을 오지급하지 않습니다.
- session_start 자동 광고 없음. 광고 제거 시 stage_clear를 웹과 native 모두 차단합니다.

## 저장 / 오프라인 / 화면

- 로컬 재실행, 최신 잔액 선택, 동일 timestamp 로컬 우선, 구버전 v2 복구, 손상/미래 스키마 처리를 확인합니다.
- 출차 중·일부 탑승·VIP/셔플 직후·실패·부활·클리어 직후 앱 종료와 재개를 확인합니다. 차량/정류장/대기열/부활 횟수/재고와 보상이 일관되어야 합니다. 미래 스키마는 업데이트 안내와 쓰기 차단, 손상 round는 현재 레벨 재시작 안내가 필요합니다.
- 힌트 반복·검색 중 차량 이동/재시작/광고·백그라운드 전환 때 오래된 추천을 제거해야 합니다. 로컬 Worker/CSP 로딩 실패나 탐색 시간 초과에도 무차감으로 게임을 계속해야 합니다. 색상 기호 모드에서 테두리·행열 안내를 확인합니다.
- iCloud 꺼짐·다른 계정·동기화 지연·용량 초과·재설치·계정 전환에도 로컬 플레이를 유지합니다. 원격 저장 완료로 오표시하지 않습니다.
- 서로 다른 기기에서 오프라인 소비/구매 후 병합 시 잔액·원장 롤백을 점검합니다. 현재 단순 최신 snapshot 선택만으로 해결되지 않는 출시 전 필수 항목입니다.
- 완전 오프라인 최초 실행과 폰트/Phaser 자산 로드, 작은 iPhone 및 iPad 정책, safe area, 백그라운드, 색약 기호, 오디오를 확인합니다.
- 개인정보/지원 링크, 스토어 가격·상품 설명·연령 등급·광고 공개를 대조합니다.
